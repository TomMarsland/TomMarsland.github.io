# A* Path Planning Algorithm

AMR coursework project for grid-based path planning. The project uses a PyQt GUI to set grid size, obstacles, start/end cells and run the planner visually.

## Files

- gui.py - PyQt interface for the path planning demo.
- pathPlanner.py - A* path planning implementation using a Euclidean-distance heuristic.

Generated cache files, editor settings and unrelated notebook material are excluded from this public portfolio copy.
