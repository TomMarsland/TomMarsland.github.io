# RL Connect Four

In-progress reinforcement learning Connect Four project. The current code includes a game environment, game logic and a DQN training script.

## Files

- env.py - Connect Four environment used by the reinforcement learning agent.
- game.py - Connect Four game logic.
- dqn.py - Deep Q-Network training code.

This is still a work in progress and may change as the agent, reward design and training loop are improved.
