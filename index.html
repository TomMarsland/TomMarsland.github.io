Beckhoff Automation

Beckhoff Automation - Main Project

The aim was to demonstrate automated CNC-style motion using Beckhoff hardware and TwinCAT. I modified the NCI control code to trace the Silverstone path, designed the HMI for control and monitoring, added 3D visualisation, and integrated EtherCAT diagnostics for real-time system feedback.

University Projects

DJI Tello Drone Flying Controller

The goal was to build and test a working controller for a DJI Tello drone as part of university work. I wrote the control logic, mapped keyboard commands to movement, and tested take-off, landing and directional movement to improve my Python and real-time control skills.

A* Path Planning Algorithm

This AMR coursework focused on grid-based path planning for an autonomous mobile robot. I implemented the A* search logic, used a Euclidean-distance heuristic, handled obstacles and start/end points, and connected the algorithm to a PyQt GUI so the route could be tested visually.

Principle of Mechanical Engineering Project

The project goal was to move object A over obstacle B using a designed mechanical system. I worked in a team through concept generation, prototyping, testing and final build, contributing to the engineering design process and practical implementation.

Research - Reduced-Order Modelling for Non-Linear Dynamics

This individual research project compared reduced-order modelling methods for non-linear dynamic systems with machine learning approaches. I reviewed the existing techniques, carried out the comparison, and wrote the final report to explain the strengths and limits of each approach.

Leo Rover Autonomous Robot Project

The goal was to build a Leo Rover system that could autonomously navigate an arena and place blocks into a bin. I contributed to mechanical assembly, learnt the software and control systems during the project, helped integrate sensors, and supported troubleshooting when the robot behaviour did not match the plan.

Formula Student AI - Bristol

The aim was to design, build, and program a fully autonomous robot for the Formula Student AI competition. I worked with a multidisciplinary team on robotics, sensor integration and control, helping the system reach competition-ready functionality.

Personal Projects

Football Computer Vision Project

The goal was to track football players from match footage and extract useful movement information. I developed the computer vision pipeline, used Kaggle data for testing, and added overlays for player tracking, movement, and team possession analysis.

Handwritten Digit Recognition using CNN

The aim was to build a simple image classifier for handwritten digits. I preprocessed the MNIST data, trained a convolutional neural network, adjusted the model structure, and evaluated its accuracy on the test set.

ROS Tracking System

The goal was to create a ROS-based tracking system for a moving tennis ball. I built the simulation, set up the tracking behaviour, and used the result to practise robot perception and motion analysis in a controlled environment.
